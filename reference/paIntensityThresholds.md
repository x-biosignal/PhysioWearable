# Physical-activity intensity ENMO cut-points

Returns the ENMO thresholds (mg) separating physical-activity
intensities for adults (Hildebrand et al. 2014 style): the lower bound
of light, moderate and vigorous activity.

## Usage

``` r
paIntensityThresholds()
```

## Value

A named numeric vector `c(light, moderate, vigorous)` in mg.

## References

Hildebrand M, et al. (2014). Med Sci Sports Exerc 46(9):1816-1824.
